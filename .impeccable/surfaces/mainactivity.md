# Surface Brief: MainActivity & Onboarding Flow

## Scope and Visitor Mode
Mode: Operate.
Scope: Native Android application (`com.chate.thesis`) covering the full enrollment/onboarding journey and real-time security dashboard.

## Direction contract

### THESIS
Continuous biometric keyboard authentication reimagined through Material 3 Expressive. We refuse stale developer-admin control panels with raw disconnected buttons; instead, we deliver a structured, rewarding onboarding journey that transforms technical biometric calibration into an intuitive, guided typing experience paired with an expressive real-time security dashboard.

### OWN-WORLD
Material 3 Expressive with Electric Cyan (`#00E5FF`) and Security Slate (`#004F58` / `#1C1B1F` / `#00363D`), expressive 24–28dp rounded containers, pill chips, stepped progress indicators, tactile prompt challenge cards, and tonal elevation.

### STORY
The user arrives to an engaging onboarding flow that clarifies zero-trust continuous verification, guides them effortlessly through Android keyboard activation and device admin permissions, guides them through natural typing prompts (pangrams and passages) with live biometric keystroke telemetry, and unlocks the real-time continuous verification dashboard with live OCSVM and Mahalanobis risk monitoring.

### FIRST VIEWPORT
Onboarding welcomes the user with an expressive hero graphic, clear value proposition card, and an expressive stepped progress bar. An interactive setup checklist highlights system requirements (IME activation & device admin status) with direct action chips, leading smoothly to the guided typing calibration arena.

### FORM
Material 3 Expressive Android Native (Jetpack Components & Material Components v1.11+).
